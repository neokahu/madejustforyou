# Review 3 — C2-reaction

**1. Strongest: E.** It names the core failure: beat 4 shows an effect with no visible cause, so the concept's buying reason is only implied. Its fix, Alex's light falling into the empty bed, pays off a prop the script already plants. That one shot fixes C2-d and C2-c without touching locked assets. It also replaces the micro-expression with a body action a phone viewer can actually see, and it catches the dead-looking panel inside the 3-second window. D finds the same shot but sells it rather than testing it.

**2. Biggest blind spot: A.** A treats this as a render job. It never asks whether the ad persuades anyone, and it waves off C2-c (the house rule against a lonely giftee) as "doesn't change what we build." Runner-up: D calls S-C2-H2 the scaling winner and doesn't deal with B's point that it reads as a human death.

**3. What all five missed:** the buyer. The script casts the grieving owner buying for himself, but the CTA says "Make one that's only *theirs*" and the store sells gifts. Most memorial purchases come from a friend or relative buying for the person grieving, and nobody in the ad is that person. Only B gets near the believability problem: a 6-inch panel throwing a legible name, or a dog shape landing in a bed (D and E), is an overpromise that invites comments and refunds.
