# MadeJustForYou — Logo Pack

Reusable brand assets. Vectors (SVG) scale to any size; PNGs are pre-rendered for favicons, app icons and avatars.

## Symbol — stitched heart
- `symbol-clay.svg` — primary, clay heart with cream stitch (light backgrounds)
- `symbol-ink.svg` — ink heart (light backgrounds)
- `symbol-honey.svg` — honey heart with ink stitch (for dark backgrounds)
- `symbol-cream.svg` — cream heart with clay stitch (for dark/photo backgrounds)
- `symbol-solid-clay.svg` — solid heart, no stitch (for very small sizes)

## Wordmark & lockups
- `wordmark.svg` — "MadeJustForYou" in Playfair Display, "Just" italic clay
- `lockup-horizontal.svg` — symbol + wordmark, side by side
- `lockup-stacked.svg` — symbol above wordmark, centered

## App icon / favicon / avatar (PNG, transparent where relevant)
- `app-icon.svg`, `app-icon-512.png`, `app-icon-180.png` — rounded clay tile with cream heart
- `favicon-32.png`, `favicon-16.png` — browser favicon
- `symbol-clay-512.png`, `symbol-ink-512.png`, `symbol-cream-512.png` — transparent symbol

## Colours
- Clay `#C15F3C` · Honey `#E0A458` · Soft Rose `#D98E85`
- Cream `#FBF6EE` · Warm Sand `#EFE4D4` · Warm Ink `#2E2822` · Stone `#8A7E70`

## Fonts
- Wordmark / display: **Playfair Display** (600)
- Body / UI: **Hanken Grotesque**
- Signature / handwritten accent: **Caveat**

## Rules
- Brand name is always the Playfair wordmark — never set in the handwritten script.
- The Caveat script is only for short warm lines ("made just for you") on tags, notes, packaging.
- Keep clear space of at least the mark's height around the logo.
- Minimum mark size 24px; below that use `symbol-solid-clay.svg`.
