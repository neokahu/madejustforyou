# CLR · Backgrounds

Reusable background sets. The customer picks one; it swaps the `BG_Color` layer.

> **A background can be a COLOR or an IMAGE — not only solid colors.**
> - **Color** backgrounds → this file (CLR, hex swatches).
> - **Image/pattern** backgrounds → stored as file assets under Clipart type,
>   `Clipart/Backgrounds/<set>/` (e.g. `CLP-BGI-01`), because they're image files.
> The Teeinblue "Background" option is wired to point at whichever set(s) a design uses —
> a color category, an image category, or both.
