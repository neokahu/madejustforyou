# Tier-1 Organic Test — GPD02 Metaphor Head-to-Head

**Goal:** find which "one-per-grandchild" metaphor resonates **before** paying a designer to build
the production component library. Cheapest test that can pick the winner.

- **Variable under test:** the **metaphor** (Garden vs Birds vs Night Sky)
- **Held constant:** product (**cream sweatshirt**), family data (Grandma · Ava, Liam, Noah), format, CTA, posting slot
- **Channels:** TikTok + Instagram Reels + Pinterest (organic, $0)
- **Primary metric:** **save rate** (saves ÷ views) — normalizes for uneven reach
- **Secondary:** buy-intent comments ("where do I get this / do you make it for [nana/mom]"), shares, watch-through
- **Window:** 48–72h per post · **Experiment card:** [`experiments/GPD02-tier1-metaphor.md`](experiments/GPD02-tier1-metaphor.md)

---

## Content direction (this is what makes or breaks it)

From the sprint's social pull: grandma content that goes viral is **sentimental, handmade,
POV storytelling** (kids' hand-painted gift = 920K plays; recipe keepsake = 193K). **Product-shot /
catalog-style videos flopped at ~110 plays** (competitor wanderprints). So:

**DO** — film it like a *personal gift reveal*, not an ad:
- POV / "the gift that made Grandma cry" framing; hands unfolding the sweatshirt; slow close-up
  panning across each flower/bird/star **as you read the grandkids' names**; if possible, a real
  grandma's reaction.
- Soft, warm, current **sentimental trending sound** (pick the trending one at post time).
- Text-on-screen hook in the first 1s; let the *names* be the emotional payoff.

**DON'T** — no white-background product spin, no price, no "Shop now" hard sell, no stock-photo feel.

**Keep the test clean:** identical treatment across all three — only the design + the metaphor word
changes. Post **one per day, same time slot, 3 consecutive days**, and rotate which goes first
across a second round if you re-run (removes day-of-week bias).

## Measurement & decision

Record per post at 48–72h: **views, saves, save rate, comments (flag buy-intent), shares.**

| Outcome | Rule |
|---------|------|
| **Winner** | highest **save rate** *and*/or most buy-intent comments — advance to **Tier-2 paid** + build the production component library for that metaphor only |
| **Two close** | run a second round (rotate order) before deciding |
| **All flat** | the issue is likely *creative/format*, not the metaphors — reshoot with stronger sentimental framing once (fair-iteration rule) before abandoning |

> Compare **within each platform** (Garden has a Pinterest home-field edge because birth-flower
> dominates there — don't let that alone crown it; weigh TikTok/Reels save rate too).

**Why organic first:** near-zero cost, and the *comments* hand you the exact wording + which
nicknames (Nana/Gigi/Mimi) to prioritize in the build. Only the winner earns the designer spend.
