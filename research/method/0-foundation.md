# Stage 0 — Dimension Libraries

The controlled vocabularies that make idea generation **combinatorial and exhaustive**
instead of random. Keep these lists living — add a row whenever discovery surfaces something
new. An idea is one pick from (most of) each column plus a creative hook.

```
IDEA = Product × Recipient × Occasion × Personalization × Emotional Angle  + a hook
```

---

## A. Products

Group by margin/producibility tier. `POD notes` flag the things that kill margin (breakage,
heavy shipping, print complexity). Fill base cost / retail once you have supplier quotes.

| Product | Tier | POD notes | Base $ | Retail $ |
|---------|------|-----------|--------|----------|
| Ceramic mug (11/15oz) | Core | Cheap, high demand, breakage in transit | | |
| Stainless tumbler (20/30oz) | Core | Higher AOV, durable, wrap print | | |
| T-shirt / hoodie | Core | Size/color variants multiply SKUs | | |
| Ornament (ceramic/acrylic/wood) | Seasonal | Q4 monster, low cost, light ship | | |
| Fleece / sherpa blanket | Premium | High AOV & giftability, heavy ship | | |
| Canvas / poster / framed print | Premium | Wall art, photo-led, fragile | | |
| Wood / acrylic sign / plaque | Premium | Home decor, sturdy | | |
| Necklace / bracelet (jewelry) | Premium | High margin, high perceived value | | |
| Candle | Core | Nice add-on, shipping restrictions | | |
| Doormat | Novelty | Funny angle winner, bulky | | |
| Pillow / cushion cover | Core | Home, photo-led | | |
| Tote bag | Core | Cheap, low AOV | | |
| Phone case | Novelty | Model fragmentation = many SKUs | | |
| Keychain / mini acrylic | Novelty | Impulse add-on, tiny ship | | |
| Puzzle / notepad / sticker sheet | Novelty | Cheap testers | | |

> Start tests on **low-cost, low-ship, low-breakage** items (mug, shirt, ornament) to keep the
> failure cost tiny; graduate proven angles to premium items (blanket, canvas, jewelry) for AOV.

## B. Recipients (relationships)

The single strongest lever in personalized gifting — people shop *for a person*.

- **Parents:** mom, dad, stepmom, stepdad, bonus mom/dad, mother-in-law, father-in-law
- **Grandparents:** grandma, grandpa, nana, papa, "first-time grandparents"
- **Partners:** wife, husband, girlfriend, boyfriend, fiancé(e), "couple / us"
- **Kids/siblings:** daughter, son, sister, brother, twins
- **Chosen family:** best friend, bestie, "soul sister", roommate
- **Work/community:** teacher, nurse, coworker, boss, coach, mentor, boss's-day
- **Pet-parent identity:** dog mom, dog dad, cat mom, cat dad, "pet memorial"
- **Self / identity:** "treat yourself", zodiac, hobby identity (gym, gardening, gamer, book lover)
- **Milestone people:** new mom, graduate, retiree, new homeowner, newlyweds

## C. Occasions (with buying windows)

`Lead` = how far before the date research/production must be locked. Windows are the *buying*
period, which opens well before the date.

| Occasion | Date | Buying window opens | Lock design by (lead) |
|----------|------|--------------------|----------------------|
| Valentine's Day | Feb 14 | mid-Jan | ~6 wks (early Jan) |
| Galentine's | Feb 13 | early Feb | ~5 wks |
| Mother's Day (US) | 2nd Sun May | early Apr | ~6 wks (late Mar) |
| Father's Day (US) | 3rd Sun Jun | late May | ~5 wks |
| Graduation | May–Jun | Apr | ~6 wks |
| Halloween | Oct 31 | late Sep | ~5 wks |
| Thanksgiving | 4th Thu Nov | early Nov | ~4 wks |
| Christmas | Dec 25 | **early Oct** | **~10–12 wks** |
| New Year | Jan 1 | mid-Dec | ~3 wks |
| **Evergreen (year-round):** | | | |
| Birthday | any | always | continuous |
| Anniversary / wedding | any | always | continuous |
| New baby / baby shower | any | always | continuous |
| Housewarming | any | always | continuous |
| Memorial / sympathy | any | always | continuous |
| Retirement | any | always | continuous |
| **Niche / audience days:** | | | |
| Nurses Week | early May | Apr | ~5 wks |
| Teacher Appreciation Week | early May | Apr | ~5 wks |
| National Pet Day | Apr 11 | late Mar | ~4 wks |
| Grandparents Day | Sep (2nd Sun) | late Aug | ~4 wks |

> **Evergreen occasions are the base load** (steady demand, no timing risk); **seasonal
> occasions are the spikes** (bigger volume, but you must respect the lead time). Maintain a
> rolling 90-day look-ahead against this table.

## D. Personalization types

What the customer customizes — often the difference between "generic gift" and "made for me".

- **Name(s):** single name, couple names, full family roster, initials, monogram
- **Photo:** portrait photo, pet photo, couple/family photo, photo-to-illustration/portrait
- **Date:** anniversary, birth date, "together since", "est." year
- **Message:** custom note, inside joke, quote
- **Place:** map / coordinates of a meaningful location, city skyline
- **Stats:** birth stats (weight/length/time), zodiac / star map, height chart
- **Count/roster:** number of kids/pets, list of names (family tree, "grandma's crew")

> Higher personalization depth = higher perceived value + harder for competitors to
> commoditize, but more UX friction. Match depth to product tier.

## E. Emotional angles (message archetypes)

The *why it lands as a gift*. Every winning listing has a clear angle.

- **Sentimental / love** — "to the moon and back", heartfelt
- **Funny / sassy** — cheeky, meme-y (huge on mugs, shirts, doormats)
- **Memorial / loss** — sympathy, "in loving memory", pet loss (strong evergreen, high emotion)
- **Milestone / achievement** — graduation, promotion, "we did it"
- **Long-distance** — "even miles apart", deployed, college kid
- **Inside-joke / identity** — fandom, hobby, "crazy dog lady"
- **Pride / encouragement** — "you've got this", identity affirmation
- **Nostalgic** — "the year we...", throwback
- **Relationship-status** — "promoted to grandma", "girl dad", new roles

> The same product+recipient flips completely on angle: a "mom" mug can be *sentimental*
> (Mother's Day), *funny* ("world's okayest mom"), or *memorial*. Treat angle as a first-class
> dimension when generating and testing.
